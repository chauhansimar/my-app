# 🤖 AI Shipping Assistant

AI-powered chatbot built using MERN Stack and Gemini AI.

## 🚀 Features

- User Authentication
- Real-time AI Chat
- Gemini AI Integration
- MongoDB Chat Storage
- Typing Animation
- Timestamps
- Clear Chat
- Responsive UI
- Profile & Logout Menu

## 🛠 Tech Stack

Frontend:
- React.js
- CSS

Backend:
- Node.js
- Express.js

Database:
- MongoDB Atlas

AI:
- Gemini AI API

## 📦 Installation

```bash
npm install
```

## ▶️ Run Frontend

```bash
npm run dev
```

## ▶️ Run Backend

```bash
node server.js
```

## 🔐 Environment Variables

Create `.env` file:

```env
MONGO_URI=your_mongodb_uri
JWT_SECRET=your_secret
GEMINI_API_KEY=your_api_key
```
